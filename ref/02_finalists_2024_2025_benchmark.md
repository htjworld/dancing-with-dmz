## 2025년 결선 진출팀 — 최종 수상팀 제외

### 1. CloudMap

- **참가 챌린지:** From EarthData to Action: Cloud Computing with Earth Observation Data for Predicting Cleaner, Safer Skies
- **프로젝트:** NASA **TEMPO 위성의 대기질 관측**을 지상 측정·기상 자료와 결합해, 대기질 예측을 일반 사용자에게 전달하는 웹 기반 앱.
- **우리 팀 참고:** 위성 기반 원천 자료를 사용자 친화적인 **지도·수치·근거 정보**로 번역하는 방법. 특정 관측 지점을 선택했을 때 어떤 상세정보를 먼저 보여줄지 참고.
- **링크:** [NASA 공식 팀 소개](https://www.spaceappschallenge.org/2025/find-a-team/cloudmap/)

### 2. Stellar Minds

- **참가 챌린지:** Will It Rain On My Parade?
- **프로젝트:** 사용자가 지정한 **장소와 날짜**에 대해 매우 덥거나 춥거나 비가 많이 오거나 바람이 강할 가능성 등 기상 위험을 알아보는 개인화 도구.
- **우리 팀 참고:** 지도와 시간의 조합, **사용자가 직접 질문·추측한 뒤 데이터 결과를 확인하는 UX**. 개별 프로젝트 구현 세부사항보다 공식 챌린지 문제 정의 중심으로 소개.
- **링크:** [NASA 공식 팀 소개](https://www.spaceappschallenge.org/2025/find-a-team/stellar-minds5/)

> **선정 상태 검증:** 공식 팀 소개에 `Global Finalist`가 표시되며, 2025 글로벌 수상팀 10개 명단에 포함되지 않는 사례만 기재했습니다. 2025년 결선 명단에는 지구과학 이외의 과제가 다수 포함되어 있고, 본 목록은 관련성이 확인된 팀만 선정했습니다.

## 2024년 결선 진출팀 — 최종 수상팀도 포함

### 3. AsturExplorers — Landsat Connect

- **수상:** Best Mission Concept
- **프로젝트:** 사용자가 위치를 지정해 **Landsat 위성 통과 시점 및 해당 위치의 반사도 관측 데이터**에 접근하도록 하는 웹앱.
- **우리 팀 참고:** 최신 서비스 개편의 **1단계 ‘위성 통과’**와 가장 유사. 위성이 지나가고 관측 영상이 단계적으로 나타나는 시퀀스를 설계할 때 참고.
- **링크:** [NASA 팀 페이지](https://www.spaceappschallenge.org/nasa-space-apps-2024/find-a-team/asturexplorers/?tab=project) · [Landsat Connect 소개](https://www.asturexplorers.space/landsat-connect-app/) · [팀 수상 안내](https://www.asturexplorers.space/asturexplorers-from-asturias-to-the-world-one-of-the-10-global-winners-of-nasa-spaceapps-challenge-2024/)

### 4. Team I.O. — G.R.O.W.

- **수상:** Local Impact
- **프로젝트:** NASA FIRMS 산불 자료와 기상 정보를 지도에 결합하고, **자연어·음성 질의**로 정보를 찾아주는 환경 데이터 서비스.
- **우리 팀 참고:** 복잡한 지도 데이터의 설명을 직관적으로 만들기. 지도에 정보를 모두 쌓기보다 **짧은 결과 카드와 단계적 상세보기**로 제공.
- **링크:** [NASA 공식 수상 소개](https://www.nasa.gov/learning-resources/stem-engagement-at-nasa/nasa-international-space-apps-challenge-announces-2024-global-winners/) · [기술·UX 사례 분석](https://crafterwiki.com/projects/grow-team-io/)

### 5. Connected Earth Museum

- **수상:** Art & Technology
- **프로젝트:** 기후·산불·해양온도·인구밀도 등 다양한 지구 시스템 데이터를 **몰입형 가상 전시관**과 인터랙티브 시각화로 구성.
- **우리 팀 참고:** 데이터 시각화를 독립 차트 모음으로 끝내지 않고, **하나의 이야기로 연결하는 연출**. 최종 결과 카드와 ‘보이지 않는 변화’ 메시지에 적용 가능.
- **링크:** [NASA 공식 수상 소개](https://www.nasa.gov/learning-resources/stem-engagement-at-nasa/nasa-international-space-apps-challenge-announces-2024-global-winners/)
- **참고:** 공식 팀 상세 페이지는 현재 `hidden by the site administrators` 상태이므로 수상 안내를 우선 링크했습니다.

### 6. GaamaRamma — WaterWise

- **수상:** Best Use of Data
- **프로젝트:** 위성 기반 증발산·기상 정보를 이용해 **농업용수·관개 의사결정**을 돕는 지도 기반 웹서비스.
- **우리 팀 참고:** 특정 지역을 사용자가 선택한 뒤, 관측 자료를 실제 해석·의사결정으로 연결하는 구도. 데이터 근거를 카드에 담는 방식.
- **링크:** [NASA 팀 페이지](https://www.spaceappschallenge.org/nasa-space-apps-2024/find-a-team/gaamaramma/?tab=project) · [WaterWise 프로젝트 분석](https://www.crafterwiki.com/projects/waterwise/)

### 7. NVS-knot — 2plant | !2plant

- **수상:** Galactic Impact
- **프로젝트:** **SMAP 표층 토양수분** 등 위성 자료와 수문 모델을 결합해 파종 적합성과 농경지 수분 위험을 시공간적으로 보여주는 도구.
- **우리 팀 참고:** **관측값, 가공 지표, 모델 추정, 불확실성**을 구분하는 설명 방식. 우리 SAR 탐지에서 후방산란 변화만으로 원인을 단정하지 않도록 설계하는 데 유용.
- **링크:** [NASA 프로젝트 상세](https://www.spaceappschallenge.org/nasa-space-apps-2024/find-a-team/nvs-knot/?tab=project) · [데모 영상](https://drive.google.com/file/d/10u8i69xK-b9ojl3y89R0_faH5hKe8Mqu/view) · [공개 웹앱 링크](https://nasa.nave-app.com/list-view)

### 8. TerraTales

- **수상:** Best Storytelling
- **프로젝트:** NASA 온실가스·기후 데이터를 **지역별 이야기, 사용자 참여형 게임, 미래 변화 예측**과 결합.
- **우리 팀 참고:** 우리 서비스의 **2단계 ‘직접 그려보기’ → 3단계 ‘실제 관측 공개’**에 가장 직접적인 스토리 UX 사례. 사용자가 먼저 행동하고 결과를 받아들이게 하는 구조.
- **링크:** [NASA 프로젝트 상세](https://www.spaceappschallenge.org/nasa-space-apps-2024/find-a-team/terratales/?tab=project) · [프로젝트 웹앱](https://terratalesjourney.netlify.app/) · [발표·데모 영상](https://drive.google.com/file/d/18fZCTpWv1b-nGf7o6hufBO35blM6vzQx/view?usp=drive_link)

### 9. 가지니 (Gajini) — OptiCrop

- **결과:** 2024 글로벌 결선 진출, 한국 판교 지역 행사 참가.
- **참가 챌린지:** Leveraging Earth Observation Data for Informed Agricultural Decision-Making.
- **프로젝트:** 지구관측 자료를 지역의 농업·가뭄·용수 문제 해결에 연결하는 농업 의사결정 접근.
- **우리 팀 참고:** 한국의 구체적인 지역 문제와 공개 위성 데이터를 연결해 설명하는 방식.
- **링크:** [NASA 2024 글로벌 결선팀 목록 — ‘가지니’ 검색](https://www.spaceappschallenge.org/nasa-space-apps-2024/awards/global-finalists/)
- **참고:** 개별 프로젝트 상세 URL을 이번 확인에서 확보하지 못해, 확인 가능한 공식 결선 목록으로 연결했습니다.

## Dancing with DMZ 단계별 추천 벤치마킹

| 우리 단계 | 우선 열어볼 사례 | 관찰할 포인트 |
|---|---|---|
| **1. 위성 통과** | AsturExplorers | 관측 시간·위치·장면 전환을 어떻게 단순한 시퀀스로 만들었는가 |
| **2. 직접 그려보기** | TerraTales, Stellar Minds | 사용자가 먼저 가설을 만들어보는 참여 구조, 장소·시간 선택 UX |
| **3. 공개 및 비교** | NVS-knot, CloudMap | 관측·비교 기준·모델·불확실성을 어떻게 구분해 설명하는가 |
| **4. 결산 카드** | Connected Earth Museum, Team I.O. | 어렵고 많은 정보를 하나의 문장과 핵심 지표로 어떻게 압축하는가 |
| **전 과정의 과학적 근거** | GaamaRamma, 가지니 | 실제 지역 문제와 NASA 데이터의 연결을 어떻게 증명하는가 |

## 바로 활용할 핵심 아이디어

1. **원천 데이터가 나타나는 순간을 ‘사건’으로 연출**: 위성 통과 → 스캔 → 관측 변화 공개.
2. **사용자 예측과 위성 관측을 명확하게 분리**: 직접 그린 점선, 실제 관측 실선, 비교 기준선을 구분.
3. **결측을 숨기지 않기**: 관측 없음·자료 미공개·품질 제외·비교 불가를 의미에 맞게 표시.
4. **레이더 신호 변화와 환경의 원인·평가를 분리**: 후방산란 증가·감소를 생태 복원/훼손으로 바로 해석하지 않기.
5. **결과 화면은 한 장의 카드처럼**: 숫자 하나, 그래프 하나, 핵심 해석 한두 문장.

### 조사 메모

- 2025년 최종 수상 10팀은 본문 대상에서 **모두 제외**했습니다. 2025년의 나머지 35개 결선 진출팀을 전수 분석한 목록은 아닙니다.
- 2024년은 사용자가 최종 수상팀 제외를 요청하지 않았으므로 2024년 수상 사례를 그대로 포함했습니다.
- 링크는 공식 팀·수상 페이지를 우선했고, 추가 데모/구현 링크는 공식 팀 설명 또는 직접 확인된 공개 자료를 연결했습니다. 영상·앱은 현재 접속 상태가 변할 수 있습니다.
- 일부 설명은 공개 프로젝트 소개를 압축한 **벤치마킹 요약**이며, 구현 기능을 직접 테스트했다는 뜻은 아닙니다.
